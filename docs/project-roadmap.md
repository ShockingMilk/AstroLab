# Astro Assist Roadmap

## Milestone 1 - Stable application baseline

- Full-screen Tkinter application
- Responsive preview layout
- Managed camera process
- Calibration profile 0
- Configurable rotation
- Keyboard controls
- Clean shutdown
- Initial documentation and tests

## Phase 1 - Camera and device management

- Camera discovery
- Sensor-mode discovery
- Camera profile selection
- Exposure controls
- Gain controls
- Focus assistance

## Phase 2 - Storage and capture

- Dynamic storage detection
- Internal and external storage selection
- Free-space safeguards
- Screenshot capture
- Video capture
- Capture metadata
- Reusable notification popups

## Phase 3 - Telescope testing

- Moon imaging
- Planetary imaging
- Barlow lens testing
- Bright-star imaging
- Star-field imaging
- Profile tuning

## Phase 4 - Observing assistance

- Target crosshair improvements
- Target-centering assistance
- Drift feedback
- Histogram
- High-frame-rate capture

## Phase 5 - Astrophotography processing

- Calibration frames
- Image stacking
- Planetary processing
- Lunar processing
- Metadata-based organization

## Phase 6 - Cluster integration

- Processing job preparation
- Python processing pipeline
- OpenMPI integration
- Distributed image processing

The Raspberry Pi should remain independently usable
for capture when the processing cluster is unavailable.
